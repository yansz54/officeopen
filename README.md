## The joke

> The break-room cake says 'Happy Birthday, Dave.' There is no Dave here. There has never been a Dave here.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Pure Node.js standard library — no network, no randomness, no clock. Two runs
write byte-identical output.
